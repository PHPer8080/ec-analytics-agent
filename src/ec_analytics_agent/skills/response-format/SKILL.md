## 役割

このスキルは分析の内容ではなく、**ユーザーへ返す最終レスポンスの形**を規定する。
どの分析（アドホック含む）であっても、回答を返す直前に必ず本フォーマットを適用する。

## 出力フォーマット（毎回適用）

1. **結論** — 要点を先出しする（1〜3文）。ユーザーの問いに対する答えを最初に述べる
2. **根拠** — 結論の裏付けとなる数値を提示する。必ず **期間・条件・件数（母数）** を添え、
   末尾に **実行した SQL** を折りたたみで付ける（下記「根拠の SQL」）
3. **示唆 / 次アクション** — 数値から言える意味づけ、または次に確認・検討すべきこと

## 根拠の SQL

Data Agent の応答の `THOUGHT` パートに、実行された SQL が含まれる。
数値の検算ができるよう、それをそのまま引用する。

````
<details><summary>実行した SQL</summary>

```sql
<Data Agent が生成した SQL をそのまま>
```
</details>
````

- 複数回問い合わせた場合は、1 つの折りたたみにまとめて並べる（折りたたみを分けない）
- SQL を取得できなかった場合はこの折りたたみを付けない（推測で書かない）
- Data Agent のリソース名は SQL ではないので出さない

## 数値の表記ルール

- すべての数値に**単位**を付ける（円 / % / 人 / 件 / 日）
- 率は分子・分母が伝わる形で示す（例: 「F2率 22%（新規1,200人中264人が転換）」）
- 大きな金額は桁区切りを入れる（例: 1,250,000円）

## 適用時の注意

- 分析スキル（`metric-interpretation` / `analysis-workflow`）の選択有無に関わらず適用する
- 情報が不足していて根拠を示せない場合は、その旨（データ未取得・母数不足）を根拠欄に明記する
- 数値を先行ターンから再掲する場合、その数値を取得した SQL も併せて再掲する
