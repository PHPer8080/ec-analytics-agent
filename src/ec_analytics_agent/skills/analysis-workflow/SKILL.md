## 役割

1回の Data Agent 問い合わせで完結しない、**複数ステップの分析手順**を提供する。
各ステップで Data Agent に何を尋ね、結果を受けて次に何を掘るかの型を示す。

## 適用手順

1. ユーザーの問いが「単発の数値取得」か「原因究明・比較・深掘り」かを判断する
2. 深掘りが必要なら、下記の代表ワークフローから該当する型を選ぶ
3. 型に沿って **Data Agent への問いを1ステップずつ**発行し、各結果を解釈してから次に進む
4. 最終的に「観測 → 要因 → 示唆」の流れで結論をまとめる

## 代表ワークフロー

### A. 異常検知 → ドリルダウン → 仮説
1. 全体指標の時系列を取得し、異常月・異常セグメントを特定
2. 異常点を軸（商品 / チャネル / 顧客セグメント / 期間）で分解
3. 最も寄与の大きい軸を深掘りし、原因仮説を1〜3個立てる
4. 仮説を裏付ける/棄却する追加データを1回だけ確認する

### B. 比較分析（前年比 / セグメント間 / 期間比）
1. 比較の基準（前年同期・他セグメント・前期）を明確化
2. 比較対象の指標を同一条件で取得
3. 差分の大きい箇所を特定し、差の要因を分解
4. 「なぜ差が出たか」を客単価×客数などの型で説明

### C. セグメント深掘り（優先度マッピング）
1. 対象母集団を2軸（例: 価値 × 状態）でセグメント化
2. 各セグメントの規模（人数・売上）を取得
3. 「規模が大きい × 改善余地が大きい」象限を優先対象として特定
4. 優先セグメントに絞った具体像を提示

## Data Agent への問い方

- 1ステップ1問い。複数の集計を一度に詰め込まない（結果の切り分けが困難になる）
- 各ステップは自然言語で具体的に（期間・対象・粒度を明示）
- 前ステップの結果を踏まえて次の問いを組み立てる（探索の文脈を保つ）
