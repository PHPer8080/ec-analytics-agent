# ワークフロー別 問いかけテンプレート

各ステップで Data Agent（Conversational Analytics）へ投げる自然言語の問いのテンプレート。
`{...}` はユーザーの文脈で埋める。**1ステップ1問い**を守る。

## A. 異常検知 → ドリルダウン → 仮説

1. 「直近{12ヶ月}の{売上}の月次推移を、前年同月比とあわせて教えて」
2. 「{異常だった月}の{売上}を{商品カテゴリ / チャネル / 顧客セグメント}別に分解して」
3. 「{寄与の大きかった軸}のうち、前年から最も変動した上位を教えて」
4. （仮説検証）「{仮説の対象}について{関連指標}を確認したい」

## B. 比較分析

1. 「{対象指標}を{今期}と{前年同期}で並べて」
2. 「差が大きい{セグメント / 期間}を特定して」
3. 「その差を{客単価と客数 / 新規と既存}に分解して」

## C. セグメント深掘り

1. 「{対象顧客}を{価値区分}×{状態区分}でセグメント化し、各セグメントの人数と売上を教えて」
2. 「{規模の大きいセグメント}に絞って{詳細指標}を教えて」

## 進行のコツ

- 各ステップの結果を要約してから次へ進む（探索の文脈を保持）
- 母数が小さいセグメントは断定を避ける
- 3〜4ステップで結論に収束させ、掘りすぎない
